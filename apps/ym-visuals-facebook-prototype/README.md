# YM Visuals — Facebook Page Concept Prototype

**Stage:** Prototype  
**Purpose:** A responsive, interactive visual concept for planning the YM Visuals official Facebook business page.

## Preview it

Open **[index.html](./index.html)** in the repository, then click **Raw** or download the file to view it in a browser. For a shareable public preview, enable GitHub Pages for this repository and publish the repository root; GitHub Pages serves static HTML without a separate app server.

Potential URL after Pages is enabled: https://yvan-star.github.io/AXORA-Development/apps/ym-visuals-facebook-prototype/  
This URL will work only after the repository's Pages publishing configuration is enabled and deployed.

## What's included

- Responsive page layout inspired by a social business page
- YM Visuals black/white/charcoal palette with restrained electric-blue accents
- Brand tagline: **Visuals That Define You.**
- Supporting line: **Simple. Clean. Effective.**
- About, service, contact, featured post, and portfolio sections
- Small demo interactions with explicit prototype notices
- No build step, packages, login, database, or installation required

## Before public launch

1. Replace the generated YM monogram with the official YM Visuals logo asset.
2. Replace portfolio concept tiles with original, approved work.
3. Verify the location/service-area wording.
4. Add an official business email, Messenger destination, and approved contact links.
5. Confirm final service descriptions, availability, and any pricing.
6. Remove or revise the prototype disclaimer only after the concept is approved and a real destination is established.

## Important limitation

This is **not** an actual Facebook Page, cannot create or manage a Page, and does not connect to Facebook/Meta. Like, message, follow, comment, and share controls are local demo interactions only. A real Page must be created and managed through Facebook, and links should be connected only after the correct official destinations are known.

## GitHub Pages

GitHub Pages can host this static prototype. In the repository, go to **Settings → Pages**, choose a publishing source/branch and the appropriate folder, then save. Publishing settings require repository permissions. Public Pages sites are accessible on the internet, so don't put credentials, private customer data, or secrets in this repository.
