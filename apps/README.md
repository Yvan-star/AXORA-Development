# Applications Directory

Use this directory only for small prototypes or experiments that intentionally belong in the AXORA Development hub.

Each app should live in a named subdirectory, for example `apps/example-app/`, and include its own README with setup, run, test, configuration, architecture, limitations, and maturity stage.

Create a separate repository instead when an app needs separate secrets, access permissions, independent deployment/release, a different stack, or confidential source.

No application is scaffolded here yet. This is an intentional empty starting point, not a claim that an app already exists.
