# Architecture Decision Records (ADRs)

Use an ADR for important decisions that would be expensive or confusing to reverse later.

Create files as `0001-short-title.md`, incrementing the number.

## Template

```markdown
# ADR 0001: Decision title

- Status: Proposed | Accepted | Superseded | Rejected
- Date: YYYY-MM-DD
- Decision owner: project/team

## Context
What problem or constraints require a decision?

## Options considered
What realistic alternatives were evaluated?

## Decision
What was chosen and why?

## Consequences
What trade-offs, risks, and follow-up work result?

## Revisit when
What new evidence would cause this decision to be reconsidered?
```
