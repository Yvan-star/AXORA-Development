# Reusable Packages Directory

Place shared libraries or components here only when there is a clear need from at least one real consumer.

Each package should document:
- Purpose and supported consumers
- Public API and compatibility expectations
- Install/build/test steps
- Versioning and changelog approach
- Dependencies and license
- Security and maintenance ownership

Keep project-specific implementation inside its app until reuse is demonstrated. No package is scaffolded yet.
